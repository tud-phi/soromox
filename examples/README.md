# Examples

This directory contains small, self-contained demonstrations of SoRoMoX APIs.
Paper benchmarks and application studies live in [`../paper_results`](../paper_results/README.md),
where code, input data, and canonical outputs are versioned together.

## Layout

```text
examples/
├── data/                         # optional inputs shared by multiple topics
├── control/
│   ├── actuation_space/
│   │   ├── figures/              # generated, ignored by Git
│   │   └── setpoint_regulation_comparison.py
│   └── operational_space/
│       ├── figures/              # generated, ignored by Git
│       └── control_tendon_actuated_pcs_with_synergistic.py
└── simulation/
    ├── articulated/              # scripts plus generated videos/
    ├── gvs/                      # scripts
    ├── hsa/                      # scripts plus generated videos/
    ├── pcs/                      # scripts plus generated videos/
    └── pendulum/                 # scripts plus generated videos/
```

An example writes generated figures or videos beside its script in `figures/`
or `videos/`. Artifact names begin with the script name so their provenance is
clear when several examples share a topic directory. These generated folders are
ignored by Git and are created on demand.

Use `examples/data/<dataset>/` only for committed inputs shared by examples in
more than one topic. Use `<topic>/data/` for committed topic-specific inputs or
for intermediate data generated by that topic; document whether each dataset is
an input or generated artifact in the example docstring or a topic README.

All built-in paths are resolved from the script location, so examples can be run
from the repository root or another working directory.
