# Geometry

The geometry utilities contain direct pose-coordinate encodings, rotation
representation conversions, and geodesic error metrics.

- `poses` converts direct pose coordinates into homogeneous transforms.
- `rotations` converts between quaternion, rotation-vector, matrix, and 6D
  rotation representations.
- `errors` computes shortest-path orientation errors for control and tracking.
